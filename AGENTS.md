## Mandatory founder rule

> **Preserve the intended effect. Do not literalize the metaphor. Search reality before inventing architecture.**

Alfonso's biological, institutional, and science-fiction language expresses serious desired capabilities/effects unless he explicitly specifies implementation form.

For any apparently impossible or metaphorical objective:

1. preserve the destination;
2. define the real observable effect;
3. separate literal requirements from analogy;
4. search existing WMI/UNIIMENTE capabilities;
5. search commodity/open-source/API/plugin/service/computer-use mechanisms;
6. use mechanism extraction/mutation/recombination only where useful;
7. identify only the residual CapabilityDeficit;
8. build the smallest missing capability;
9. verify the underlying outcome.

Do not turn `morphogenesis` into a requirement for digital biology or dynamic organization. Canonical morphogenesis is resourceful functional capability formation/reconfiguration in response to a verified discrepancy.

OMNIMORPH is optional organization-design machinery and should be used only when organizational topology beats static workflow, one model/tool, an external solution, or another simpler alternative.

## Evidence

Business and venture success is measured by the named real effect—accepted output, verified customer/institutional outcome, reconciled economics, or other stated metric—not by internal architecture, biological resemblance, model consensus, or simulation success.
